# Serverski program (server program)

## Definicija
Serverski program je program koji pruža uslugu drugim programima i prima njihove zahteve preko [[Protokol|protokola]]; „serverski“ označava ulogu, ne računar na kojem radi.

## Primer
HTTP serverski program radi na aplikacionom [[Server|serveru]] Fakturisa, prima zahtev pregledača i vraća stranicu.

## Napomene
- „Klijent“ i „server“ u mrežnoj razmeni obično označavaju uloge programa. Isti program može u različitim razmenama imati različite uloge.
- „DNS server“ može značiti program ili računar; naziv precizirati kada je razlika bitna.
