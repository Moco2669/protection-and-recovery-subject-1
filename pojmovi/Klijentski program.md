# Klijentski program (client program)

## Definicija
Klijentski program je program koji započinje komunikaciju ili traži uslugu od drugog programa koristeći [[Protokol|protokol]].

## Primer
Pregledač je klijentski program kada šalje [[HTTP]] zahtev serverskom programu Fakturisa. DNS stub resolver je klijent kada šalje upit rekurzivnom resolveru.

## Napomene
- Klijent označava ulogu programa, ne nužno računar korisnika. [[Server]] je računar, [[Serverski program]] je uloga programa.
